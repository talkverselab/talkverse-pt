## 1. 콘셉트
장면 컷이 주인공인 리스본 이야기. 컷을 넘기며 읽고, 걸리는 동사는 그 자리에서 활용표로, 걸리는 소리는 독음 표시로 푼다. 포르투갈어의 어려운 두 곳 — **동사 6인칭 활용**과 **약해지고 콧소리가 나는 모음** — 을 회화를 읽는 흐름 안에서 바로 해결하는 것이 이 앱만의 칸이다.

## 3. 칸 ① — 회화 리더 + 동사 활용 시트 (아이패드 가로, 칸 900 이상)
```
┌────┬──────────────────────────────┬──────────────────────────────────────┐
│레일│ 대화 스크립트                 │ 장면 컷 (점토, 리스본 카페)             │
│배우│ 1 ● Olá! Sou o Minjun.        │ ┌──────────────────────────────────┐ │
│기● │     올라! 쏘우 우 민준.        │ │ [Tiago 가 에스프레소를 건넴]       │ │
│복습│     안녕! 나는 민준이야.  🔊   │ │      말풍선: O que queres beber?  │ │
│탐색│ 2 ● O que [queres] beber? ◀현재│ └──────────────────────────────────┘ │
│나  │     우 끄 께레쉬 베베르?       │ 캡션: 뭐 마실래?                      │
│    │     뭐 마실래?            🔊   │ ┌─ 동사 활용 ─────────────── ✕ ─┐    │
│    │ 3 ● Um café, por favor.       │ │ querer · 원하다  ● -er · 불규칙 │    │
│    │                               │ │ 직설법 현재                      │    │
│    │                               │ │ eu quero      nós queremos      │    │
│    │                               │ │ [tu queres]   vós quereis       │    │
│    │                               │ │ ele/ela quer  eles/elas querem  │    │
│    │                               │ │ 이 문장: tu · 현재 → 친구에게 묻기│    │
│    │                               │ │ [과거] [미래] [🔊 전부 듣기]      │    │
│    │                               │ └────────────────────────────────┘    │
├────┴──────────────────────────────┴──────────────────────────────────────┤
│ ▶  ━━━━━━●──────── 2/8   0.8× 1.0×   [PT] [독음] [한국어]   🇵🇹 Portugal ▾ │
└──────────────────────────────────────────────────────────────────────────┘
```
- 동사는 문장 안에서 군 색 점선 밑줄. 탭하면 시트가 **장면 컷 칸 아래 1/3** 에 붙는다(스크립트는 가리지 않음). 컷은 위로 줄어 2:1 로. 다른 동사를 누르면 시트 내용만 바뀐다.
- 지금 칸은 azulejo-soft 바탕 + azulejo 글자. 불규칙은 보라 점 + 「불규칙」 칩. 시제 칩은 그 동사에 데이터가 있을 때만.
- 900 미만(세로·폰): 컷 위(44%)·스크립트 아래, 활용 시트는 하단 시트(높이 50%).

## 4. 칸 ② — 발음 표시 + 판 전환
```
독음 칩 켜짐:
  2 ● O que queres beber?
      우 끄 께레(쉬) 베베르?         ← 어말 s = 「쉬」를 연한 azulejo 바탕
      ˘약모음은 작게·회색:  끄(que) · 드(de)
      ~비모음은 물결 밑줄:  엔따웅(então) · 앵(em)
  🔊 길게 누르면 0.6× 로 그 줄만
```
- 범례는 독음 칩 옆 ⓘ 에 한 번만(약모음·비모음·어말 쉬 세 줄).
- **판 전환 칩** `🇵🇹 Portugal ▾ / 🇧🇷 Brasil` — 회화 홈 맨 위 오른쪽과 리더 컨트롤 바 오른쪽 끝. 국기 대신 글자 칩을 써도 됨(앱 그림엔 국기 없음 원칙 — 칩 안 작은 이모지만). 브라질판 데이터가 없으면 「브라질판 준비 중」 안내 후 Portugal 유지.
